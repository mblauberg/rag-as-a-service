## Dependency Upgrades

### Critical Upgrades for Python 3.13 Compatibility

1. **asyncpg**: `0.29.0` → `0.30.0`
   - Reason: v0.29.0 had C extension compatibility issues with Python 3.13's changed C API
   - v0.30.0 adds full Python 3.13 support

2. **tiktoken**: `0.5.2` → `0.12.0`
   - Reason: v0.5.2 lacked pre-built wheels for Python 3.13, requiring Rust compiler
   - v0.12.0 includes Python 3.13 wheel support

3. **FastAPI**: `0.109.0` → `0.120.0`
   - Full Python 3.13 support added in v0.115.8
   - v0.120.0 includes Python 3.14 support

4. **Pydantic**: `2.5.3` → `2.12.0`
   - Python 3.13 compatibility improvements
   - Better type annotation handling for Python 3.13+

5. **lxml**: `4.x` → `5.x`
   - Python 3.13 compatibility fixes
